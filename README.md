# JC4832W535 Tanks Game

Проект игры «Танчики» на плате JC4832W535 (ESP32-S3 + AXS15231B).

## Текущее состояние (рабочий каркас)

- ✅ Дисплей AXS15231B работает, альбомная ориентация 480×320
- ✅ Тачскрин AXS15231B работает, координаты корректные
- ✅ Тестовый экран с четырьмя углами и центральным квадратом
- ⏳ Игровая логика (танки, карта, снаряды) — в разработке
- ⏳ Bluetooth-геймпад — в разработке

## Аппаратная конфигурация

### Дисплей (QSPI)
- BL:   GPIO 1
- CS:   GPIO 45
- SCK:  GPIO 47
- D0:   GPIO 21
- D1:   GPIO 48
- D2:   GPIO 40
- D3:   GPIO 39

### Тачскрин (I2C)
- SDA:  GPIO 4
- SCL:  GPIO 8
- INT:  не используется (-1)
- RST:  не используется (-1)

## Ключевые моменты

### Ориентация экрана

`JC3248W535_Display display;` — конструктор без аргументов.
Поворот задаётся после `display.begin()`: `display.setRotation(1);`

### Маппинг координат тача

Тач отдаёт портретные координаты (320×480), экран альбомный (480×320).
Формула преобразования:

```cpp
int x = rawY;
int y = 319 - rawX;
```

## Полная перерисовка кадра

AXS15231B не поддерживает частичное обновление. Каждый кадр нужно:

1. gfx->fillScreen(BLACK) — очистить
2. Нарисовать всё заново
3. display.flush() — отправить один полный кадр
