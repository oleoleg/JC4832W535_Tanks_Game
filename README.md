# JC4832W535 Tanks Game

Проект на плате JC4832W535 (ESP32-S3 + AXS15231B).
Многофункциональное устройство: игра «Танчики», видеодомофон, файловый менеджер.

## Что работает

- ✅ Дисплей AXS15231B, альбомная ориентация 480×320
- ✅ Тачскрин AXS15231B, координаты попадают точно
- ✅ Модульная UI-архитектура (кнопки, события, менеджер)
- ✅ Меню с кнопками навигации
- ✅ Wi-Fi Manager — портал настройки через телефон
- ✅ Веб-сервер для работы с SD-картой
- ✅ Файловый менеджер: список с размером, свободное место, загрузка с прогрессом, удаление
- ✅ SD-карта на отдельной шине HSPI
- ✅ Отладка через встроенный USB-JTAG

## В разработке

- ⏳ Стек экранов (навигация вперёд/назад)
- ⏳ Игра «Танчики»
- ⏳ Видеодомофон (Wi-Fi + камера)
- ⏳ Bluetooth-геймпад

## Аппаратная конфигурация

### Дисплей (QSPI)
- BL:   GPIO 1
- CS:   GPIO 45
- SCK:  GPIO 47
- D0:   GPIO 21
- D1:   GPIO 48
- D2:   GPIO 40
- D3:   GPIO 39

### Тачскрин (I2C)
- SDA:  GPIO 4
- SCL:  GPIO 8
- INT:  не используется (-1)
- RST:  не используется (-1)

### SD-карта (SPI, HSPI)
- SCK:  GPIO 12
- MISO: GPIO 13
- MOSI: GPIO 11
- CS:   GPIO 10

**Важно:** SD-карта на HSPI, дисплей на FSPI. Это разные контроллеры,
конфликта SPI-шины нет.

## Ключевые моменты

### Инициализация дисплея:

```cpp
JC3248W535_Display display;   // без аргументов
display.begin(); //Поворот задаётся после этой строки
display.setRotation(1);        // 1 = альбом, 3 = альбом перевёрнутый
gfx = display.getCanvas();
```

### Маппинг координат тача:

Тач отдаёт портретные координаты (320×480), экран альбомный (480×320).
Формула преобразования:

```cpp
int x = rawY;
int y = 319 - rawX;
```

## Полная перерисовка кадра

AXS15231B не поддерживает частичное обновление. Каждый кадр нужно:

1. gfx->fillScreen(BLACK) — очистить
2. Нарисовать всё заново
3. display.flush() — отправить один полный кадр

## Отладка

В platformio.ini:

    build_type = debug
    debug_tool = esp-builtin
    debug_speed = 5000

Точки останова работают, переменные видны.
Для загрузки без отладки — закомментировать build_type = debug и нажать Upload.

## Wi-Fi и веб-интерфейс

При первом запуске плата поднимает точку доступа `Tanks-Setup` (пароль `12345678`).
Подключись к ней с телефона, открой браузер, введи пароль от домашней сети.
Плата сохранит настройки и подключится к роутеру.

Веб-интерфейс доступен по IP платы (виден в Serial). Функции:
- Список файлов на SD с размером
- Свободное место
- Загрузка файлов с прогресс-баром
- Удаление файлов
